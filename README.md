# ORQ Haute Parfumerie (دار عطور أو آر كيو)

متجر عطور رجالية نيش فاخر بتصميم سينمائي أسود وذهبي (Black & Gold Haute Parfumerie)، مطور باستخدام **Next.js 16 (App Router)** و**Tailwind CSS** مع دعم كامل للغة العربية (RTL First).

---

## 🌟 نظرة عامة على المشروع (Project Overview)

ORQ هي علامة تجارية متخصصة في العطور الرجالية الفاخرة ذات الكاريزما العالية وتركيزات الـ *Eau de Parfum* المكثفة.
يقدم المتجر تجربة مستخدم حسية فريدة من نوعها تتضمن:
- **مدخل سينمائي ثلاثي الأبعاد بالدخان الذهبي والرذاذ الجزيئي (Cinematic Entry):** دخول انسيابي يجسد زجاجة العطر في الفراغ دون أي قواطع أو حدود كرتونية.
- **الهرم العطري التفاعلي (Interactive Scent Pyramid):** استكشاف تفاعلي للقمة، القلب، والقاعدة العطرية لكل عطر.
- **نظام التصفية حسب الشخصية والمناسبة (Scent Mood Filtering):** تصفية ذكية (عود وهيبة ملكية، جذاب وسهرات، منعش ورياضي، رسمي ودافئ).
- **تصميم متجاوب بالكامل (Mobile-First Luxury):** ترتيب مخصص لشاشات الموبايل يضمن ظهور زجاجة العطر فوق النصوص في جميع النماذج.
- **سلة مشتريات فورية (Side Drawer Cart):** تجربة شراء سهلة مع دعم الدفع عند الاستلام (COD) وعينات التجربة المجانية.

## 🎨 نماذج الواجهة الرئيسية المتاحة (Design Concepts)

المشروع يحتوي على 3 مفاهيم تصميم رئيسية جاهزة للمعاينة المباشرة:
1. **النموذج 1: السينمائي الملكي (`/preview/concept-1`):**
   - هيرو سينمائي ثلاثي المراحل مع كانفاس الدخان الذهبي والشهب المتطايرة.
   - استعراض الهرم العطري التفاعلي.
   - شبكة عطور منتقاة مع أنيميشن تمرير ناعم.
2. **النموذج 2: العصري التفاعلي (`/preview/concept-2`):**
   - هيرو رذاذ العطر مع محاكاة فيزيائية لانطلاق الرذاذ وأشعة النور الحجمية.
   - شريط الفلاتر السريع حسب طابع الحضور.
   - قسم باقة الهدايا الحصرية (صندوق الـ 750 ج.م مع توفير 45%).
3. **النموذج 3: المعرض البانورامي (`/preview/concept-3`):**
   - بانوراما سينمائية لأسطول العطور الـ 12.
   - تقسيم المجموعات إلى: خط العود الملكي (Royal Oud Dynasty) وخط الحضور العصري (Signature Line).
   - فلسفة دار العطور (The Creed of ORQ).

## 🛠️ البنية التقنية (Tech Stack)

- **Framework:** Next.js 16 (App Router, Turbopack)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **State Management:** React Context API (Cart & Scent Filters)
- **Animations:** Custom Canvas Physics (Particle Mist & Volumetric Light Rays) + CSS Hardware-Accelerated Transforms + ScrollReveal (IntersectionObserver)
- **Typography:** Tajawal (العربية) + Cinzel (اللاتينية الفاخرة)

## 🚀 كيفية التثبيت والتشغيل المحلي (Getting Started)

### المتطلبات الأساسية:
- Node.js 18+
- npm أو pnpm أو yarn

### خطوات التشغيل:
```bash
# 1. الدخول لمجلد الواجهة الأمامية
cd frontend

# 2. تثبيت الحزم
npm install

# 3. تشغيل خادم التطوير المحلي
npm run dev
```

افتح المتصفح على: [http://localhost:3000](http://localhost:3000)
