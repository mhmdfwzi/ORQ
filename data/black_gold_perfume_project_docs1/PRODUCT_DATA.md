# PRODUCT DATA - جاهزية الكتالوج والصور

المراجعة: 2026-10-28. هذا جرد للمصادر وقالب تجهيز بيانات، وليس كتالوج بيع معتمدًا.

## 1. ما تقوله المصادر

[الكتالوج](../ORQ_perfume_collection.pdf) يحتوي 12 سجل عطر في أول صفحتين، مع عمود أسعار مقترحة لـ100 مل. بقية الصفحات لا تضيف سجلات منتجات إلى النص المستخرج.

كل الأسماء والتصنيفات والنفحات أعلاه **مسودة تحتاج D03**. ليست كل منتجات المقارنة في عمود Original Names هي المنتجات التي يبيعها ORQ؛ يحفظ العمود كمرجع داخلي فقط، ولا ينسخ إلى اسم المنتج أو SEO أو وصف منشور تلقائيًا.

## 2. اختلافات يجب حسمها

- الصور تعرض مقاسات 30 و50 مل، بينما التسعير في الكتالوج مقترح لـ100 مل. لا نحسب سعر 50 مل بقسمة سعر 100 مل.
- توجد صور عرض باقة بسعر 750 EGP تضم 50 مل ومعطر سيارة و4 عينات. هذا عرض مختلف؛ لا يثبت تعارض سعر لنفس SKU ولا يعد سعر بيع معتمدًا.
- الكتابة DARKNIGHT في الكتالوج وDARK NIGHT في بعض الصور تحتاج اسم عرض موحدًا؛ لا تنشئ منتجين بسبب المسافة.
- توجد كتابات إضافية أو غير واضحة على بعض العبوات والتغليف؛ لا تضف منتجات مثل VELVET من صورة وحدها.
- صور العبوات والملصقات متفاوتة؛ لا نجزم بأنها صور المنتج النهائي أو مولدة. يلزم تأكيد المطابقة وحق الاستخدام لكل أصل.
- لا توجد قائمة مخزون أو SKU أو أسعار معتمدة لكل حجم، ولا شعار أصلي منفصل ضمن الملفات الحالية.

## 4. قالب سجل منتج قابل للبيع

يجهزه مسؤول المنتجات؛ سجل مستقل لكل نسخة:

| الحقل | المطلوب |
| --- | --- |
| product_name / slug | كتابة معتمدة، ومعرف URL ثابت بعد النشر |
| sku | معرف فريد لكل حجم/نسخة، لا يعتمد على الاسم وحده |
| size_ml / concentration | حجم وتركيز حقيقيان؛ لا يستنتجان من المقارنة بعطر آخر |
| price_minor / currency | سعر نهائي ووحدة عملة معتمدة؛ حالة الضريبة وفق D02 |
| stock_on_hand / source | مخزون فعلي ومصدر وتاريخ تحديث؛ الصفر لا يعني مخزونًا مجهولًا |
| family / notes / description | نصوص ونفحات راجعها صاحب المنتج؛ دون وعود ثبات غير مثبتة |
| media / alt | صورة أساسية مطابقة وصور إضافية عند توفرها، ونص بديل |
| offer_type | زجاجة أو باقة، ومكونات الباقة وكمياتها عند اعتمادها |
| publication_status | مسودة / قيد المراجعة / معتمد للنشر / مخفي |
| approval | صاحب الاعتماد وتاريخه ومرجع البيانات |

أي حقول ناقصة تبقي SKU مسودة. لا تعرض قيمة افتراضية مخترعة لإكمال البطاقة. يمكن إخفاء حقل اختياري غير متوفر؛ السعر والحجم والهوية والمخزون شروط للشراء.

## 5. تسليم الأصول

- احتفظ بالأصول الحالية دون استبدال؛ النسخ المحسنة منفصلة.
- لكل SKU منشور: صورة أساسية واضحة للعبوة المطابقة، ويفضل صورة تغليف/تفاصيل عند توفرها.
- لواجهة Hero: نسخة أفقية وأخرى للهاتف، دون سعر أو CTA داخل الصورة، مع شعار أصلي مستقل. النص والزر في HTML.
- تسجل خريطة الأصل ← المنتج/النسخة ← موضع العرض ← المطابقة/حقوق الاستخدام.
- يحول الاستيراد الأحرف العربية إلى صيغة Unicode موحدة ويراجع التكرارات؛ لا يستورد أسعار الاقتراح أو عمود المقارنة مباشرة إلى الإنتاج.
- إذا اعتمدت باقة، يسجل كل مكون مطلوب حتى لو كان هدية بسعر صفر للعميل؛ له تكلفة ومخزون وقاعدة استبدال.
