# ORQ Perfume - Frontend Storefront (Next.js 16)

واجهة متجر عطور ORQ الرجالية الفاخرة، مبنية باستخدام Next.js (App Router) وTypeScript وTailwind CSS بتصميم سينمائي أسود وذهبي (Black & Gold).

## النماذج المنفذة (CINE-00 إلى CINE-03)

تم تنفيذ المقترحات الثلاثة كاملة كصفحات ومكونات متجاوبة ومتوافقة مع RTL:

1. **النموذج 1: السينمائي الغامض (The Cinematic Reveal / The Monolith)**
   - المسار: `/preview/concept-1` (وهو الافتراضي في `/preview` و `/`).
   - المزايا: تكوين غير متماثل (58% للزجاجة على بازلت أسود، 42% للنص العربي)، تسليط الضوء على عطر الأيقونة (متمرد)، تشريح الهرم العطري التفاعلي، وشبكة 4 عطور بمساحات تنفس واسعة.

2. **النموذج 2: الفخامة العصرية والتحويل السريع (Modern Commerce & Mood Discovery)**
   - المسار: `/preview/concept-2`.
   - المزايا: شريط إعلاني للقيمة المضافة، شاشة مقسومة للتحويل السريع على عطر ALPHA مع مؤشرات الثبات والفوحان، شريط فلاتر الطابع العطري (Mood Selector)، وشبكة تسوق سريع، وقسم باقة الهدايا (750 ج.م).

3. **النموذج 3: معرض الفخامة البانورامي (The Olfactory Gallery)**
   - المسار: `/preview/concept-3`.
   - المزايا: بانوراما سينمائية عريضة للأسطول الكامل، تقسيم المتجر إلى خطين عطرين (خط العود الملكي + خط الحضور العصري والجاذبية)، وفلسفة الدار.

4. **صفحة تفاصيل المنتج الكاملة (PDP):**
   - المسار: `/preview/products/[slug]`.
   - المزايا: اختيار الأحجام (50 مل / 100 مل) مع تحديث فوري للسعر، محدد الكمية، تشريح المكونات الخاصة بالعطر، وضمانات التجربة، وسلة مشتريات تفاعلية منبثقة (Cart Drawer).

## أوامر التشغيل والتحقق

```bash
# الانتقال لمجلد الواجهة
cd frontend

# تشغيل خادم التطوير المحلي
npm run dev

# فحص الأنواع وبناء الإنتاج
npm run build

# تشغيل الفحص البرمجي
npm run lint
```
